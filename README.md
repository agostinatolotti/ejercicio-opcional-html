# Ejercicio opcional - HTML semántico

Este proyecto corresponde al ejercicio opcional de estructura semántica de HTML.

## Estructura

Las páginas del sitio utilizan las principales etiquetas estructurales de HTML5:

- `<header>` para la cabecera.
- `<nav>` para la navegación principal.
- `<main>` para el contenido principal y único de cada página.
- `<footer>` para la información de cierre.

## Páginas

- `index.html` - Página de inicio.
- `acerca.html` - Página Sobre mí.
- `contacto.html` - Página de contacto.

## Criterios

Cada página contiene:

- Un único `<header>`.
- Un único `<nav>` dentro del `<header>`.
- Un único `<main>`.
- Un único `<footer>`.
- Los enlaces de navegación principal se encuentran dentro de `<nav>`.
- La estructura se mantiene consistente entre las tres páginas.

## Ejecución

Para visualizar el proyecto, abrir `index.html` en un navegador web y utilizar los enlaces del menú para navegar entre las páginas.
